# NOTE on where this file actually lives: this repo is served as a GitHub
# Pages *project* page (https://aayushgour.github.io/clipnest/), so this
# file builds to https://aayushgour.github.io/clipnest/robots.txt — NOT the

# the origin root is already equivalent to "allow everything." This file
# becomes fully authoritative the moment a custom domain is attached (its
# root and the Pages publish root become the same thing). Shipping it now
# documents intent and costs nothing. See plan §0 for the full explanation.
